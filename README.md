# Car Damage Detection System

This is an individual project that detects car damage using image and video processing techniques.

## Objective
To automatically identify and highlight damaged areas on car images and videos.

## Technologies Used
- Python  
- OpenCV  
- Machine Learning  

## How to Run

### 1. Install required libraries
pip install -r requirements.txt
### 2. Run for image input
python app.py --mode image --input car.jpg --output result.jpg
### 3. Run for video input
python app.py --mode video --input car.mp4 --output result.mp4
